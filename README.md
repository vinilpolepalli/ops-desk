# Ops Desk

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Async (YC S26) works in. Not affiliated with or endorsed by Async.

Ops inbox for a fictional small business. Every email, item and agent draft is synthetic; the DRAFTED -> NEEDS APPROVAL -> APPROVED -> SENT flow is a local state machine - no real messages are sent or received, and every agent draft requires human approval.

Static export of a Next.js app. Built with Claude Code.
